## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
AI Factory telemetry is only useful if every source agrees on the same physical and logical identity: site, rack, node, GPU index and UUID, NVLink domain and partition, compute tray and switch tray, and the fabric port each NIC plugs into. No fixture models GPUs today; host and Kubernetes nodes carry no GPU identity. Two hardware shapes are needed: PCIe GPU servers (typically 4 to 8 GPUs per 2U/4U node, air-cooled) and rack-scale NVL72 systems (18 compute trays of 4 GPUs plus Grace CPUs, 9 NVSwitch trays, one NVLink domain per rack, liquid-cooled). DCGM, driver logs, Redfish, NMX, BCM, Mission Control, the scheduler, storage clients and both fabrics all join on this fixture, so it is a frozen seam: design and review it before any dependent construct starts.
<!-- SECTION:DESCRIPTION:END -->
