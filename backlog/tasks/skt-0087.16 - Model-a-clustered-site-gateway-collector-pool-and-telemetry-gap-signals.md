## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
AI Factory designs send all egress through a clustered pool of identical Alloy gateways with separate roles (OTLP receive, central scrape, syslog, cloud forwarding) and disk-backed sending queues for metrics, logs and traces; host collectors hold no buffer. Collector configuration comes from Fleet Management through a proxy at the gateway. The observability-failure journey needs queue depth and capacity, failed and dropped sends, config reload failures, cluster peer state, scrape failures, syslog parse errors and credential expiry, and telemetry-gap alerts must distinguish a silent source from a failed component. alloy_health already emits part of this (signals/fm.md).
<!-- SECTION:DESCRIPTION:END -->
