## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
In a causal workload, one request with a Fault marks the metric window faulted (causalSpanWindow), and every span-metric row of the workload then switches from the legacy latency draw to real span durations. Rows for services the fault never touches jump (measured on acme-ai-platform authoring: auth verify-token 106 -> 508 ms, collab-editor 114 -> 507 ms) because real hop durations differ from the legacy draw distribution. Only rows whose hops actually carry a fault or failure in the window should cycle real durations; other rows keep the legacy draw (and the legacy engine draw count). Blocks SKT-0182.02 F1/F2 and the private demo's causal stories.
