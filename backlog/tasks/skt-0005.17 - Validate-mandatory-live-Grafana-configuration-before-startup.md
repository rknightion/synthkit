## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Non-empty strings currently satisfy live configuration, so malformed sink URLs, non-numeric instance IDs, transposed endpoints, and unreachable DNS/TLS can survive startup and fail only during asynchronous delivery. Add a redacted preflight with clear boundaries between static validation and live authorization.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Mandatory Prometheus, Loki, and OTLP endpoints are parsed and validated for expected HTTPS URL shape before live mode starts
- [ ] #2 Required instance/user identifiers are validated for their documented shape without logging their values
- [ ] #3 A redacted preflight reports each mandatory lane as statically valid, unreachable, unauthorized, or ready without printing tokens
- [ ] #4 Network/auth checks have bounded timeouts and distinguish DNS, TLS, 401/403, and endpoint-path failures
- [ ] #5 Dry-run remains credential-free and does not perform live network checks unless explicitly requested
- [ ] #6 Tests use local fake endpoints and cover malformed, unreachable, unauthorized, and successful configurations
<!-- AC:END -->
