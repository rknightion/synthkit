## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
BMCs, switches, storage arrays and management-plane appliances in an AI Factory cannot run an agent; they send RFC 5424 or RFC 3164 syslog to a central Alloy listener (loki.source.syslog or otelcol.receiver.syslog), which maps source IPs to device names, labels by site, device, source type and severity, and forwards to Loki. Messages that fail parsing are dropped and only visible through the receiver's error counters. synthkit emits journald-shaped host logs but nothing shaped like a syslog receiver's output, so every network-attached source below would otherwise reinvent it. This is a mechanic library shared by the owning constructs, not a construct of its own.
<!-- SECTION:DESCRIPTION:END -->
