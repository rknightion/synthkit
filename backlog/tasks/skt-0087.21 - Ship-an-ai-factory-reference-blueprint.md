## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Operators and solution engineers need one loadable blueprint that stands up a complete, generic AI Factory: mixed PCIe and NVL72 compute, an admin and a user Kubernetes cluster, the scheduler, storage, both fabrics, the NVLink and cluster-management planes, power and cooling, the gateway pool and platform automation. Designs for these estates use 60-second collection so every series stays at one data point per minute, and bottom-up sizing lands at roughly 1,000 to 1,200 active series per GPU all-in, with host CPU series (driven by core count), fabric per-interface counters and NVLink per-port telemetry outweighing DCGM itself.
<!-- SECTION:DESCRIPTION:END -->
