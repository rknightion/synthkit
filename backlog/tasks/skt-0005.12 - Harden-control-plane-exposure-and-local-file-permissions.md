## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Protect operational surfaces when users move beyond loopback and when synthkit runs on shared hosts. Mutation Basic auth is plaintext without TLS, read routes expose topology, and setup/staging permissions are broader than necessary. Correct inaccurate claims about persisted git-token values.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Non-loopback startup requires an explicit trusted-network or TLS-proxy acknowledgement and warns/fails when CONTROL_TOKEN is absent
- [ ] #2 Documentation states which GET and mutation surfaces are authenticated and never suggests sending Basic credentials over plaintext untrusted networks
- [ ] #3 A decision is implemented and documented for authenticating sensitive read routes such as raw blueprint/config topology
- [ ] #4 Setup creates .env mode 0600 and blueprint/state directories and staged files with least-privilege modes
- [ ] #5 Runbook/security docs correctly state that blueprint source state persists token_env_var names, not resolved token values
- [ ] #6 Security review covers bind, auth, read exposure, filesystem permissions, and backward compatibility
<!-- AC:END -->
