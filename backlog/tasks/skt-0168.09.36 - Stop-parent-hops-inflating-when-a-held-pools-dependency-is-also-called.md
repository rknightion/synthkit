## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
In a causal app, a pool held across a dependency that the same node also calls stretches the node's own server span beyond the dependency factor (acme collab-editor x3.25 for a x2.49 dependency slowdown; live-assistant x4.38): the hold and the call both add the slowed latency. Make a node's duration count the slowed dependency once.
