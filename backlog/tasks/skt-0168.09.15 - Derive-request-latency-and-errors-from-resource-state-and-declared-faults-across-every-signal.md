## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Today an incident scales configured rates, so metrics move together but no log or trace explains why. Model resources a request passes through (connection pools, concurrency limits, queues, quotas, dependency health, credentials) and faults that perturb them (exhausted pool, throttled concurrency, failing or slow dependency, expired credential, failing validation rule). Each request's latency, outcome, status and error type follow from that state, and spans (status, exception events), logs (error class and message, trace correlation), span metrics, custom metrics and AWS and broker constructs all derive from the same per-request outcomes. Neighbours see timeouts, retries and upstream 5xx. Opt-in per blueprint.
<!-- SECTION:DESCRIPTION:END -->
