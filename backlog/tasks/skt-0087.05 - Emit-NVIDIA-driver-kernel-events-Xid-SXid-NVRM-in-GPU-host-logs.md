## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The GPU fault workflow starts from an Xid burst and pivots from the DCGM Xid counter to the driver's kernel log lines for the same GPU and time window. The host construct already emits journald streams (signals/host.md) but no NVIDIA driver content, and NVSwitch-bearing systems also log through the fabric manager service (SXid). Without these lines the GPU fault, failed job and support-evidence journeys stop at a metric.
<!-- SECTION:DESCRIPTION:END -->
