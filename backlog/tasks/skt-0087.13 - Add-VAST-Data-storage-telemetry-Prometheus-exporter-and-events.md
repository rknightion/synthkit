## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Storage latency, metadata performance and client behaviour directly drive GPU utilisation, checkpoint time and job runtime, so the slow-job journey needs storage alongside GPU and fabric. VAST exposes Prometheus-compatible metrics endpoints covering cluster, CNode and DNode health, physical and logical capacity, data reduction, per-protocol throughput, IOPS and latency, metadata latency, quotas, VIP pools, client activity and alarms, and sends events and alarms through the logging path. Dataset paths, filenames and user-provided values must never become labels.
<!-- SECTION:DESCRIPTION:END -->
