## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Model-level metrics are usually owned by workload teams rather than the AI Factory platform team, but demos and workload-team stacks need inference serving on the same GPUs: request rate, queue time, time to first token, tokens per second, KV-cache usage and batch size. synthkit's gen_ai constructs model hosted APIs and gateways, not self-hosted serving engines on GPUs.
<!-- SECTION:DESCRIPTION:END -->
