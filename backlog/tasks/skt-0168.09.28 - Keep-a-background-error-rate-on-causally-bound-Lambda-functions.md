## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
A Lambda function bound to a causal concurrency resource takes every series from the model, so it loses its captured baseline error fraction (the model only fails work through faults). Allow a bound function to declare a small background error fraction applied to admitted invocations, deterministic from the seed unit, alongside model-derived Errors.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A bound function with a declared background error fraction emits that share of Errors at baseline and adds model failures under a fault
- [ ] #2 Bound functions without it and unbound functions are unchanged
