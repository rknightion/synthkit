## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
An app with traffic.from_resource mints requests by StochasticRound of the queue's served rate per tick, so its log lines and traces are a random draw around the rate rather than one per served event; the bound Lambda construct uses deterministic whole-event carries, so app logs and CloudWatch Invocations disagree in any window (found reviewing the private demo). Mint from_resource requests from the same whole-event carry the bound construct uses.
