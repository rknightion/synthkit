## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Base Command Manager is the cluster manager under Mission Control. Its CMDaemon Prometheus exporter on each head node (disabled by default, TLS-only, client-certificate authenticated) exposes node state, service state, health check results, measurables, triggers and alert state; on liquid-cooled racks the leak-detection measurables also reach Prometheus through BCM. BCM service logs and platform events go through the logging path. A collector scraping it with an expired client certificate silently loses the whole management plane.
<!-- SECTION:DESCRIPTION:END -->
