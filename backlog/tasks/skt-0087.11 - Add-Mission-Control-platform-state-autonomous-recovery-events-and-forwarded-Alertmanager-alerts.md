## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Mission Control is the control plane for NVL72 racks and ships its own kube-prometheus-stack, Alertmanager, Loki and Grafana, which operators leave unmodified. Designs that also want the data in Grafana Cloud collect it twice: poll the Mission Control API, scrape the in-cluster exporters for the autonomous recovery services with an Alloy deployed into the admin and user clusters, collect the same logs in parallel, and forward Mission Control Alertmanager alerts by webhook. Recovery telemetry covers hardware-side workflows (firmware update state, validation, diagnostics, component health actions) and, where Autonomous Job Recovery is deployed, failed-job detection, eligibility, requeue or restart, checkpoint recovery, resource isolation and outcome. Job IDs belong in logs, never metric labels.
<!-- SECTION:DESCRIPTION:END -->
