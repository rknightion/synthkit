## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
On Kubernetes GPU clusters the GPU Operator deploys the driver, device plugin, DCGM exporter, GPU feature discovery and MIG manager, and the Network Operator manages RDMA NICs. Both expose metrics, their operand pods show up in kube-state-metrics, and the device plugin is what makes GPUs appear as an extended resource on nodes and pod requests. AI Factory designs collect these through the standard Kubernetes path.
<!-- SECTION:DESCRIPTION:END -->
