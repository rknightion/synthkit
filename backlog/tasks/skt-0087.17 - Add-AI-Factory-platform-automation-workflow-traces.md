## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Platform automation (node provisioning, firmware rollout, drain and return to service, storage provisioning, self-service portals) is where AI Factory designs use traces: workflow and task duration, retries, failures, approvals, target system, API status and latency, with trace-derived metrics for long-term reporting. Spans carry operational metadata only, never payloads, secrets or command output. Platform traces and user workload traces are routed to different stacks by the collector, so a classifying resource attribute is needed to exercise that routing. The app workload's workflow node type may already cover most of this.
<!-- SECTION:DESCRIPTION:END -->
