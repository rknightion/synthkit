Accessibility

The skeleton region is a single role="status" with the label "Loading runtime", so a screen reader hears one message instead of forty empty cells; the bars themselves are aria-hidden. The in-flight state announces a phase ("Applying volume 2x, running") and never a fabricated percentage. Inline errors carry role="alert", name the failing request and keep the retry adjacent to the failure. Toasts are polite status regions, capped at two, dismissible, and never used for an error the operator has to act on: the warn toast reports a background failure and links to the view where the action lives. The dry-run state is a word in the status bar and a badge in the sidebar, not a colour. Contrast: skeleton bars are decorative only; every state sentence is fg-soft at 8.9:1 light and 9.4:1 dark.
