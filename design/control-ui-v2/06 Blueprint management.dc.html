Accessibility

Unsaved state is text ("◆ unsaved changes") in the top bar and above the field, so it does not rely on the Save button being enabled. Validation results are a role="status" region: the summary reads status word, name, then estimate, and each diagnostic names the exact YAML path. The confirm dialog is a modal with focus trapped, focus starting on Cancel, and the target named in mono in the title; the description says what will not happen, as the voice rules require. A typed confirmation is required here because the staged YAML is destroyed, and the field is a labelled input rather than placeholder-only. Escape cancels; the backdrop is not the only way out. Contrast: dialog copy 8.9:1 light and 9.1:1 dark; destructive button text on its 12 percent tint 5.0:1 light and 5.6:1 dark.
