Accessibility

The blueprint identity is the page title, the browser title and the last breadcrumb crumb, in mono. The rolled-up status word sits beside the title and repeats in the attention aside with its own note, so nothing depends on the row colour. Tabs are a real tablist with arrow-key movement; the accent underline is decorative. Steppers are number inputs with the bounds in their accessible description ("default 3, minimum 1, maximum 24"), so the mono meta line is not the only source. The switch is a checkbox reporting on or off in text next to it. Disable blueprint is a destructive button that opens the confirm dialog on screen 06 and keeps focus on Cancel. Contrast: accent link on bg-surface 5.1:1 light, 6.7:1 dark.
