Accessibility

The volume slider is a real range input with aria-valuetext of "2 times, default 1 times", and the numeric field is a second, equal route to the same value. Switches are checkboxes with the state written beside them ("on" or "off"), so no toggle depends on the accent fill. Presets are radio buttons in a group labelled Master volume, with the default one marked in its label rather than only by position. Reset all to defaults is destructive, sits outside the primary slot and is confirm-gated with a count of the knobs it will clear. Contrast: status-warn figure on bg-canvas 4.7:1 light and 6.1:1 dark; switch track is decorative, never the sole signal.
