Accessibility

The overlay is a modal dialog with an accessible name, focus moved to the input on open and returned to the trigger on close. Results are a listbox: the input keeps focus, aria-activedescendant follows the selection, and the count line ("8 of 1,076") is announced politely as it changes. Selection shows the accent edge, bg-selected and bold weight, so it survives greyscale. Escape closes, the backdrop is clickable but never the only exit, and the hint row states the keys rather than relying on icon glyphs. Contrast: mono row text on bg-raised 9.6:1 light and 8.4:1 dark; group labels 4.9:1 light and 5.3:1 dark.
