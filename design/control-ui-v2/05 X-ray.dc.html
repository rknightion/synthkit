Accessibility

The disclosure caret is a real button with aria-expanded and an accessible name naming the construct. The open row is marked with the accent inset edge and bg-selected, and the drill is the row that follows, so tab order matches reading order. Copy buttons state the count they will copy and announce the result in the status region rather than only changing colour. The capped note is a word beside the meter, never the meter colour alone. Read-only view: no mutations, so nothing here can be triggered by keyboard alone. Contrast: mono body on bg-surface 9.2:1 light, 8.6:1 dark; kind labels in accent 5.1:1 light, 6.7:1 dark.
