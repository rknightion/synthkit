Accessibility

Nav landmarks: one nav per group with an accessible name from its mono label. The active item carries aria-current="page"; the accent left edge is decorative. Posture and telemetry rows read shape, word, then note, so state never depends on colour or on the retired pulse animation. The status bar is a role="status" region with aria-live="polite". Focus is a 2px accent outline at 2px offset on every interactive element, never removed. Sidebar text sits on bg-surface in both themes: fg-soft on surface is 7.4:1 light and 8.1:1 dark.
